# Data Files

Download the training data from [link coming soon]:

- `preprocessed_data.pkl` (21.6 GB) — Preprocessed expression matrix (385,675 cells × 15,000 genes) with metadata, batch labels, and train/val/test split indices.
- `M3_improved_gene_embedding.pkl` (~30 MB) — Gene Ontology functional embeddings generated using the M3 BERT method (384-dimensional gene representations).

Place both files in this directory before running training or embedding extraction.
