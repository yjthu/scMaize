# Model Checkpoints

Download the pretrained checkpoints from [scmaize website](https://www.scmaize.com/#download):

- `scMaizeExp_best.pt` (75.3 MB) — scMaizeExp, epoch 55 (best validation MSE).
- `scMaizeGO_best.pt` (97.8 MB) — scMaizeGO, epoch 65 (best validation MSE).

Place both files in this directory before running embedding extraction or downstream analysis.
