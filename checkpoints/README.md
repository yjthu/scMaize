# Model Checkpoints

Download the pretrained checkpoints from [scmaize website](https://www.scmaize.com/#model):

- `scMaizeExp.pt` (75.3 MB) — scMaizeExp, epoch 55 (best validation MSE).
- `scMaizeGO.pt` (97.8 MB) — scMaizeGO, epoch 65 (best validation MSE).

Place both files in this directory before running embedding extraction or downstream analysis.
